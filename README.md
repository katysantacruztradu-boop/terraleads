# TerraLeads - Consultora de Marketing para SaaS de IA

Proyecto local para desarrollar el sitio web, estrategia de contenido y sistema de conversiones de una consultora de marketing B2B especializada en empresas SaaS de IA.

## Objetivo

Crear una web que funcione como motor de generacion de leads cualificados, no como tarjeta de presentacion. La web debe comunicar posicionamiento, demostrar autoridad y convertir visitantes en oportunidades comerciales medibles.

## Documentos principales

- `index.html`: primera version estatica de la web.
- `styles.css`: estilos responsive de la web.
- `scripts.js`: calculadora de demos perdidas.
- `docs/01-estrategia-web-y-contenido.md`: estrategia completa de posicionamiento, estructura web, lead magnets, SEO + IA y roadmap de 30 dias.
- `docs/02-roadmap-operativo-30-dias.md`: plan ejecutable por semanas para lanzar y conseguir los primeros leads.
- `docs/03-mensajes-y-copy-base.md`: mensajes base para home, servicios, CTAs y contacto.
- `docs/06-tasks-desarrollo-web.md`: backlog y tareas de desarrollo web.
- `.codex/rules/project-rules.md`: reglas de desarrollo, contenido, CRO y calidad.
- `.codex/agents/`: perfiles de agentes especializados para trabajar el proyecto.
- `.codex/skills/marketing-saas-ia/`: skill local para mantener consistencia estrategica.

## Como ver la web

Abrir `index.html` directamente en el navegador. La version actual es estatica y no requiere servidor local.

## Principio rector

La consultora no vende visibilidad. Vende claridad, confianza, conversion y pipeline para SaaS de IA B2B.
