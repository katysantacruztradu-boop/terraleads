# Reglas del Proyecto

## Estrategia

- Mantener el nicho: consultora de marketing para SaaS de IA B2B.
- Priorizar conversion, pipeline y confianza por encima de visibilidad generica.
- Conectar todo mensaje con un dolor comercial concreto.
- Evitar claims vagos si no pueden traducirse a comportamiento medible.

## Copywriting

- Escribir de forma directa, especifica y orientada a accion.
- Hablar de problemas de negocio antes que de tacticas.
- No abusar de terminos como innovador, disruptivo, crecimiento exponencial o 360.
- Usar titulares que indiquen para quien es, que problema resuelve y que resultado busca.
- Cada seccion debe acercar al visitante a una decision.

## CRO

- Cada pagina debe tener un CTA primario.
- Los formularios deben calificar, no solo capturar.
- Los CTAs deben reflejar intencion: diagnostico, auditoria, calculadora, llamada.
- Incluir prueba cerca de puntos de decision.
- Reducir friccion donde el usuario aun no percibe valor.
- Medir clics, formularios iniciados, formularios enviados y reservas.

## SEO + IA

- Crear contenido para preguntas conversacionales y de evaluacion.
- Priorizar temas MOFU y BOFU antes que contenido educativo generico.
- Incluir respuestas directas al inicio de los articulos.
- Usar tablas, checklists, definiciones claras y ejemplos aplicados.
- Citar fuentes confiables cuando se usen datos.
- Crear investigacion propia para aumentar autoridad y citabilidad.

## Diseño web

- La primera pantalla debe comunicar nicho, problema, resultado y CTA.
- Evitar una estetica de agencia generica.
- No usar secciones decorativas sin funcion comercial.
- Mantener jerarquia visual clara.
- Mostrar prueba, proceso y oferta antes del CTA final.

## Calidad

- Antes de publicar una pagina, verificar:
  - Propuesta de valor clara.
  - CTA visible.
  - Objeciones principales respondidas.
  - Prueba o evidencia incluida.
  - Evento de conversion definido.
  - Siguiente paso evidente.
