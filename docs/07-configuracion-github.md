## Comandos utilizados

```bash
git init
git branch -M main
git remote add origin https://github.com/katysantacruztradu-boop/kathyweb.git
git add .
git commit -m "Initial website strategy and static landing"
git push -u origin main
```

## Flujo recomendado

Para guardar cambios futuros:

```bash
git status
git add .
git commit -m "Descripcion clara del cambio"
git push
```

## Nota Windows

Git fue instalado con `winget`. Si una terminal abierta antes de la instalacion no reconoce `git`, cerrar y abrir una nueva terminal.
